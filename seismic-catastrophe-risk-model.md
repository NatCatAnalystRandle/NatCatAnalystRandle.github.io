**From the USGS National Seismic Hazard Model to portfolio insurance and reinsurance loss**

This case study documents the development of a reproducible earthquake catastrophe-risk modeling workflow that connects probabilistic seismic hazard, stochastic event simulation, physical damage, economic loss, insurance terms, and portfolio risk metrics.

The goal of the project is to demonstrate how an earthquake catastrophe model can be constructed from the underlying hazard model through the financial risk outputs used in insurance and reinsurance.

---

## 1. Why I Built This Project

Catastrophe-risk models connect physical hazard with financial consequences.

For earthquake risk, this requires more than estimating ground shaking at individual locations. A portfolio model must represent:

1. which earthquakes may occur;
2. how frequently they occur;
3. the ground motion generated by each event;
4. how exposed assets respond;
5. the resulting physical and economic damage;
6. how insurance and reinsurance structures transform those losses; and
7. how the resulting loss distribution is summarized using catastrophe-risk metrics.

This project was developed as an end-to-end implementation of that workflow using the USGS National Seismic Hazard Model as the earthquake source model.

---

## 2. Model Architecture

The baseline workflow is:

**USGS NSHM → Rupture Rates → Stochastic Event Catalog → Ground Motion → Damage → Ground-Up Loss → Insurance → Reinsurance → AAL / OEP / AEP / PML**

Each stage produces an output that becomes the input to the next stage.

This structure makes it possible to trace uncertainty and loss development through the complete catastrophe-risk modeling chain.

---

## 3. Earthquake Source Model

The project uses the **USGS 2018 Conterminous United States National Seismic Hazard Model** as the underlying seismic source model.

The source model contains earthquake source definitions, magnitude-frequency distributions, source geometry, epistemic logic-tree branches, and occurrence information.

A key modeling task was converting these source definitions into rupture-level annual occurrence rates suitable for stochastic event simulation.

---

## 4. Rupture Occurrence Rates

The USGS model contains several different source representations and magnitude-frequency formulations.

The workflow therefore extracts and validates rupture-level information before generating stochastic events.

Particular attention is given to separating:

- physical source scaling;
- epistemic branch weights;
- magnitude-frequency distributions; and
- annual occurrence rates.

This distinction is important because logic-tree alternatives cannot automatically be treated as independent additive earthquake sources.

---

## 5. Stochastic Event Catalog

The rupture occurrence model is transformed into a synthetic annual earthquake catalog.

The catalog represents many possible realizations of future earthquake activity and forms the common probabilistic foundation for the remaining calculations.

Each simulated event retains information needed for subsequent ground-motion and loss calculations.

---

## 6. Ground-Motion Simulation

For each earthquake event, ground motions are generated across the building portfolio.

The baseline model includes:

- event-level ground-motion variability;
- site-level residual variability; and
- source-appropriate ground-motion calculations.

The baseline workflow intentionally excludes spatial correlation between site residuals.

This provides the reference model that will later be compared against a spatially correlated implementation.

---

## 7. Building Damage and Ground-Up Loss

Simulated ground motions are translated into building damage and economic loss.

The result is the **ground-up loss**, representing the physical economic consequence before insurance conditions are applied.

This stage connects the engineering representation of earthquake damage with the financial component of the catastrophe model.

---

## 8. Insurance and Reinsurance

Insurance terms are applied to the ground-up losses to estimate the allocation of loss among different financial participants.

The workflow calculates:

- uninsured loss;
- gross insured loss;
- retained loss; and
- ceded reinsurance loss.

This allows the same physical catastrophe to be viewed from both an engineering-loss perspective and an insurance portfolio perspective.

---

## 9. Catastrophe-Risk Metrics

The simulated annual loss distributions are summarized using standard catastrophe-risk metrics.

### Average Annual Loss

Average Annual Loss (AAL) represents the long-run expected loss per year.

### Occurrence Exceedance Probability

The OEP curve describes the probability that the largest individual event loss in a year exceeds a specified amount.

### Aggregate Exceedance Probability

The AEP curve describes the probability that total annual loss from all events exceeds a specified amount.

### Probable Maximum Loss

Return-period losses are obtained from the exceedance curves to describe low-frequency, high-severity portfolio loss scenarios.

---

## 10. Validation

Validation is treated as part of the modeling workflow rather than as a final step.

Checks are performed throughout the project to verify:

- source-model interpretation;
- rupture occurrence rates;
- stochastic catalog generation;
- ground-motion calculations;
- loss calculations;
- insurance transformations; and
- final catastrophe-risk metrics.

The objective is to make the workflow reproducible and auditable rather than simply generate final loss numbers.

---

## 11. Baseline Model

The current implementation represents the completed baseline catastrophe-risk model.

The baseline uses conditionally independent within-event site residuals and provides the reference loss distribution for the project.

This version already produces the complete chain from earthquake source modeling through insurance and reinsurance portfolio-risk metrics.

---

## 12. Next Extension: Spatial Correlation

The next phase will introduce spatial correlation in within-event ground-motion residuals.

Importantly, the correlated and baseline models will use the **same stochastic event catalog**.

This will allow differences in portfolio loss to be attributed to the dependence assumption rather than differences in earthquake occurrence.

The analysis will examine how spatial correlation affects:

- portfolio loss distributions;
- tail risk;
- OEP and AEP curves;
- PML estimates; and
- retained and ceded reinsurance losses.
